Hard Edge Cases I'd Explicitly Handle

This is where I think your CEO will spend time testing. Make these first-class scenarios, not afterthoughts:

Scenario	Expected behavior
Company has no careers page	Report "No careers page found", no fabricated script
Careers page exists but no jobs	Output empty JSONL, mark as successful
Jobs exist but none in India	Output empty JSONL with reason "No India jobs found"
India jobs spread across multiple pages	Discover pagination and collect all
GraphQL backend	Introspect requests and generate GraphQL scraper
Infinite scroll	Detect termination condition automatically
Bot protection	Fail gracefully with evidence instead of hanging
Missing fields	Emit null, never guess
Duplicate jobs	Deduplicate by stable job_id or URL
Relative URLs	Normalize to absolute URLs
Invalid dates	Preserve date_posted_text, set parsed date to null
API rate limiting	Retry with exponential backoff
Script fails after generation	Enter repair loop automatically
